# Phishing Message Detection with Deep Learning

Train a text classification model on labelled messages to identify likely
phishing messages, and evaluate its false positives and false negatives.

Two deep learning models (**TextCNN** and **BiLSTM + Attention**, PyTorch) are
trained and compared against a classical **TF-IDF + Logistic Regression**
baseline. The evaluation looks closely at the errors: confusion matrices,
FP/FN rates, threshold trade-offs, cost-sensitive thresholds, and the
misclassified messages themselves.

The full write-up is in [report/REPORT.md](report/REPORT.md).

## How to run

```bash
pip install -r requirements.txt

# Everything at once (download -> train -> evaluate -> demo), roughly 30-60 min on a CPU
python run_all.py

# ...or step by step
cd src
python data_prep.py
python baseline.py
python train.py --model cnn
python train.py --model bilstm
python evaluate.py
python predict.py --demo
```

### Classify your own messages

```bash
cd src
python predict.py --text "Your account has been suspended. Verify now at http://secure-login.example"
python predict.py --model cnn --text "..."       # choose model: baseline | cnn | bilstm
python predict.py --file messages.txt              # one message per line
python predict.py --interactive
```

The BiLSTM prints the words its attention layer focused on, which explains
each decision.

### Web UI

```bash
cd ui
streamlit run app.py        # or double-click ui/run_ui.bat on Windows
```

Opens at http://localhost:8501 with six pages: overview, analyze a message,
batch scan, live model performance (threshold slider), error explorer, and
dataset & method. Details in [ui/README.md](ui/README.md).

## Dataset

[Phishing Email Dataset](https://huggingface.co/datasets/zefang-liu/phishing-email-dataset)
(18,650 labelled emails, "Safe Email" / "Phishing Email"). After removing empty
rows and exact duplicates, 17,511 messages remain (10,975 safe, 6,536 phishing).
They are split 70 / 15 / 15 into train / validation / test, stratified by class.
The test set is used only once, for the final evaluation.

The repository includes the trained models and the test split. The raw dataset and the
train/validation splits are not committed: `python src/data_prep.py` downloads the
dataset and recreates identical splits (fixed random seed).
